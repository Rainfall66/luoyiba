# 螺一把 · 二重螺旋角色猜测游戏(单机版)

> **非官方粉丝作品** —— 与《二重螺旋 Duet Night Abyss》及其开发 / 发行方无关。
> 猜角色类 Wordle 玩法:输入角色名,根据逐属性颜色反馈,6 次机会内猜出目标角色。

纯静态、零依赖、双击即玩:把整个文件夹拷到任何电脑,浏览器打开 `index.html` 就能玩,无需 Node / 数据库 / 联网。

## 玩法

- 系统随机选一名角色作为答案(当前 **31 名已实装角色**,另有 2 名仅存档不参战,见下);
- 输入角色名(带自动补全),每次猜测新增一行逐属性反馈;
- 🟩 **绿色(命中)** —— 属性 / 阵营 / 性别与答案相同;势力 / 版本 / 近战精通 / 远程精通与答案**完全一致**
- 🟨 **黄色(接近)** —— 势力 / 版本 / 近战精通 / 远程精通**有共同项**(如答案是「单手剑/双枪」,你猜「单手剑/突击枪」);生日相差 15 天以内(跨年按环形计算)
- ▲▼ **箭头** —— 版本提示目标版本更高/更低;生日提示更晚/更早(**按自然年内排名**,非环形方向,如 1月1日 vs 12月25日:1月1日更早)
- ➖ **"-"** —— 未知属性(3 名主角的生日与势力未录入,对比按灰色处理)
- **搜索别名**:输入 仗剑游(刻舟)、确定的明天(贝蕾妮卡)、雾海引渡人(妮弗尔夫人)等也能联想
- **拼音联想**:输入**全拼或首字母**都能找到角色 —— `kezhou` / `kz` → 刻舟,`blnk` → 贝蕾妮卡,`flx` → 法露茜;忽略大小写、空格、中点与连字符。⚠️ **拼音仅用于联想候选,不能直接提交**,需点选候选项后再提交(避免 `lise` 这类歧义输入误提交)
- 🖼 **图片** —— 输入框下拉候选与猜测行显示角色小头像(游戏内那套 256×256 头像);猜中/查看答案时在结算弹窗放大展示
- 6 次机会内猜中角色名即胜;战绩与最近目标保存在本机浏览器(localStorage)

### 属性说明

- **属性**:光 / 暗 / 水 / 火 / 雷 / 风
- **阵营**:海伯利亚帝国 / 华胥 / 卢卡共和国 / 艾利西安传颂会 / 夜航者小队 / 无阵营
- **势力**:如 第十三军团 / 山外山·飘零人 / 海伯利亚皇室 / 枯荣阁 / 应天尉 …;上游把「无所属」写成了字面的 `无`(12 名角色),它和空值 `-`(3 名主角)不是一回事
- **近战精通**:单手剑 / 长柄 / 重剑 / 双刀 / 鞭刃 / 太刀(刻舟为「全部近战」)
- **远程精通**:手枪 / 双枪 / 榴炮 / 霰弹枪 / 突击枪 / 弓(刻舟为「全部远程」)
- **性别**:男 / 女;3 名主角的性别由玩家自选,记为「男/女」
- **版本**:角色实装版本(可猜角色为 1.0 ~ 1.6;仅存档的 SP黎瑟是 1.7、莉莉蔻是 2.0)

> 数据库收录 33 条角色记录,其中 **莉莉蔻** 与 **SP黎瑟** 尚未完整加入《二重螺旋》正式服,
> 标记为「仅存档」:不会成为答案、不出现在候选里、直接输入完整名字也无法提交。
> 注意 `SP黎瑟` 被排除**不影响**已在游戏内的 `黎瑟`,两者是独立记录。

## 自定义角色数据

角色数据在 `characters.js`(暴露为 `window.LUOYIBA_CHARACTERS`),字段说明见文件头注释:

```js
{ id: 1503, nickname: "刻舟",
  属性: "光",              // 光 / 暗 / 水 / 火 / 雷 / 风
  阵营: "华胥",            // 六大阵营
  势力: "山外山·飘零人",    // 细分势力(可为空)
  性别: "男",              // 男 / 女(主角为「男/女」)
  近战精通: ["全部近战"],   // 武器精通·近战行
  远程精通: ["全部远程"],   // 武器精通·远程行
  版本: "1.1",             // 实装版本
  birthday: "1101",        // 生日(四位字符串 "MMDD","" = 未录入)
  alias: "仗剑游",          // 搜索别名(角色称号)
  可用: true,              // false = 仅存档,不参与对局
  avatar: "images/head-kezhou.webp",   // 小头像
  images: ["images/head-kezhou.webp"], // 结算大图用
  pinyin: "kezhouzhangjianyou", pinyinAbbr: "kzzjy" } // 拼音联想用(仅联想,不可直接提交)
```

- 生日用**四位字符串**表示,一位数月份前补 0:`0101` = 1月1日、`1101` = 11月1日、`""` = 未录入;
  非法日期(如 `0230` 2月30日)按未知处理;`0229` 是合法生日(妮弗尔夫人就是这天);
- 改完保存刷新即生效 —— 但注意 `characters.js` 是**自动生成**的,手改会在下次生成时被覆盖。

## 图片资源

- `images/` 共 **33 张 WebP**,是游戏内角色小头像(`T_Head`),统一 **256×256**;
- 文件名统一用 **ASCII 拼音 slug**(如 `head-kezhou.webp`、`head-zhujue-dark.webp`),避免中文文件名在 zip 解压、URL 编码上的兼容问题;
- 体积参考:单张 25~95 KB,整套约 2.2 MB;
- 想换图/加图:把图片放进 `images/`,在 `characters.js` 对应角色的 `avatar` / `images` 里填相对路径即可;图片加载失败会自动隐藏,不会出现破图。

## 文件结构

```
├── index.html                  # 入口(开始页 / 游戏页 / 规则与结算弹窗)
├── app.js                      # 全部逻辑:选目标 / 判定 / 补全 / 棋盘 / 图片 / 存档

├── characters.details.json     # 同一批角色的完整资料(基础攻击 / 生命 / 防御 / 护盾 / 神智)
├── style.css                   # 样式(深青底 #00111d + 荧光青柠 #bdff00)
├── images/                     # 33 张角色小头像(256×256 WebP)
└── LICENSE                     # AGPL-3.0
```

## 技术说明

- 纯原生 HTML/CSS/JavaScript,无框架、无构建、无外部依赖,支持 `file://` 直接打开;
- **移动端自适应**:9 列棋盘在窄屏自动收紧字号与列宽,底部输入坞(键盘弹起自动贴底)、安全区适配与大触控目标;
- 判定规则:集合类属性(势力 / 近战精通 / 远程精通 / 版本)走「完全相同绿、有交集黄」,精确类属性(属性 / 阵营 / 性别)走「相同绿」,生日环形 ±15 天;
