# 螺一把 · 二重螺旋猜角色(单机版)

> **非官方粉丝作品** —— 与《二重螺旋 Duet Night Abyss》官方毫无关系。

Wordle 式玩法:系统偷偷藏一个角色,你来猜名字,每猜一次就吐一排绿/黄/灰,**6 次机会**定胜负。

**想直接开玩 → 双击 `game/index.html`。** 纯静态、零依赖、不用联网。

- 玩法、判定规则、常见吐槽:[`game/README.md`](game/README.md)
- 想加背景音乐:[`game/docs/BGM指南.md`](game/docs/BGM指南.md)
- 角色数据怎么来的、怎么更新:[`tools/`](tools/)（面向维护者,与游戏运行无关）
