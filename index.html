    游戏规则

    系统随机选一名角色作为答案,你输入角色名,每次猜测会新增一行,逐属性给出反馈。

    反馈颜色

    • 绿色(命中) —— 属性 / 出生地 / 性别 / 版本 与答案相同;势力 / 近战精通 / 远程精通 与答案完全一致
    • 黄色(接近) —— 势力 / 近战精通 / 远程精通 有共同项(如答案是「单手剑/双枪」,你猜「单手剑/突击枪」);生日相差 15 天以内(跨年按环形计算)
    • 灰色 —— 与答案不同、无任何共同项,或该属性为未知("-")
    • 箭头 —— 生日按自然年内排名提示更晚/更早(非环形:如 1月1日 vs 12月25日,1月1日更早)

    属性说明

    • 属性:光 / 暗 / 水 / 火 / 雷 / 风
    • 出生地:海伯利亚帝国 / 华胥 / 卢卡共和国 / 艾利西安传颂会 / 夜航者小队
    • 势力:如 第十三军团 / 水仙平原 / 山外山·飘零人 / 海伯利亚皇室 / 夜航者小队 / 枯荣阁 / 应天尉 …,部分角色无势力,显示「无」
    • 近战精通:单手剑 / 长柄 / 重剑 / 双刀 / 鞭刃 / 太刀(刻舟为「全部近战」)
    • 远程精通:手枪 / 双枪 / 榴炮 / 霰弹枪 / 突击枪 / 弓(刻舟为「全部远程」)
    • 性别:男 / 女(3 名主角性别由玩家自选,显示「男/女」)
    • 版本:角色实装版本(1.0 ~ 2.0)
    • 搜索:支持称号联想,如 刻舟→仗剑游、贝蕾妮卡→确定的明天、妮弗尔夫人→雾海引渡人
    • 拼音联想:输入全拼或首字母也能找到角色,如 kezhou、kz → 刻舟,blnk → 贝蕾妮卡。拼音仅用于联想,需点选候选项后再提交

    胜负

    角色名猜对即胜;6 次仍未猜中或主动查看答案则失败。
